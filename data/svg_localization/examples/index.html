The same target at three resolutions

Identical question, identical answer in normalized coordinates, identical fraction of the image. Only the pixel budget changes — which is what makes the ladder a clean resolution test rather than a target-size test.

Locate the described UI element in the screenshot and return the point at its center.
Use a normalized coordinate system where x=0 is the left edge, x=1000 the right edge, y=0 the top edge, and y=1000 the bottom edge.
Always return your single best guess, even if you are uncertain.

What these questions do not ask

Every target string is quoted in its own prompt, so the model matches a string rather than resolving a description to a referent. ScreenSpot-Pro instead asks things like "stop the bilibili download in android virtual machine in android studio", usually pointing at an icon with no text at all. This set has zero icon targets, and its smallest target is ~4.5× larger than ScreenSpot-Pro's. Absolute scores here are not comparable to that arm — only within-dataset contrasts and the shape of the precision curve are. See EVAL.md §1.1.
