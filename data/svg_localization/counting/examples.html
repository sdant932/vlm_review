One counting question per chart type, asking about the structure that type is made of. Gold comes from the semantic record captured when the scene was built, not from counting marks in the raster, and 678 of 714 are additionally cross-checked against the labels actually drawn — a table's row count against rows×columns cell labels, a flowchart's box count against its node labels. Counts are identical at all three resolutions, so the same question doubles as a resolution probe.
Scoring. Exact integer match (exact_count), which also returns signed error — the sign separates stopping early from over-counting.
These questions run on the existing scenes. No image was re-rendered to create them — they are derived from scenes.jsonl and point at the same PNGs and SVGs as the localization set. A model can therefore be scored on all three sets over identical pixels.
